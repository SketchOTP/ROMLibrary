# Plan workflow

Use the Planner module. Reconcile current goal, checkpoint, evidence and actual affected code. Search applicable decisions and failures. Triage every proposed action for direct and indirect effects, newly implied obligations and affected future work. For material or uncertain work, trace relevant causal dependencies in the actual domain and record alternatives, evidence/unknowns, goal alignment and a reassessment trigger. A low-risk reversible task needs only a concise reasoned check. Write the directive with dependency path, scope, acceptance, evidence and stop/rejoin conditions. Load full history only when targeted retrieval cannot resolve material alignment uncertainty. The Conductor resolves material consequences before READY; Scribe records the decision.
